# اختبار العطلة القضائية

نموذج أول لاختبار قانوني تفاعلي: سؤال في كل شاشة، تصحيح فوري مع السند النظامي، وتقييم في النهاية.

- الصفحة: `index.html` (ملف واحد، بدون أي مكتبات خارجية عدا خط Almarai من Google Fonts).
- المحتوى مبني على جدول «العطلة القضائية حول العالم»، والمعلومات للتوعية العامة وتُراجع قبل النشر الرسمي.
